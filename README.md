## Окружение и запуск

```bash
python3 -m venv .venv
.venv/bin/pip install tiktoken tokenizers huggingface_hub anthropic
```

```bash
.venv/bin/python exp01_tokenization_ru_vs_en.py
.venv/bin/python exp02_randomness_coffee_names.py   # системный python3, без зависимостей
.venv/bin/python exp03_tokenizers_multi.py
```

Токенайзеры Qwen3, Gemma 3, Llama 4 и Claude 1/2 скачиваются с Hugging Face автоматически. Чтобы добавить актуальные модели Claude (Opus, Sonnet, Haiku, Fable), запустите опыты 1 и 3 с ключом: `ANTHROPIC_API_KEY=... .venv/bin/python exp03_tokenizers_multi.py`. Без ключа эти колонки пропускаются.

## Сводка выводов

1. **Язык влияет на цену.** Один и тот же текст на русском, казахском или в транслите занимает больше токенов, чем на английском; у старых токенайзеров (GPT-4, Claude 1/2) разрыв 2–4 раза, у новых с большим словарём — 1.1–2 раза.
2. **Казахский дороже всех** на любом токенайзере (1.4–3.3x относительно английского).
3. **Транслит не экономит:** на новых токенайзерах русский латиницей около 1.7x и заметно дороже кириллицы.
4. **Китайский** на новых токенайзерах стоит как английский или дешевле (0.83–1.03x), на старых дороже в 1.5–1.64 раза.
5. **Числа:** Qwen3 и Gemma 3 режут их по цифрам (53–54 токена на строку, где GPT-4o и Llama 4 тратят 34).
6. **Случайность:** один промпт в трёх чистых чатах даёт разные списки, но с общим ядром клише: «Крема» и «Ристретто» дословно, а идеи «Зерно…», «Обжарка…» и «Тёплый…» повторились во всех трёх чатах.
7. **Claude 3+ и 5:** токенайзер закрыт; по чужим измерениям токенов у него заметно больше, чем у GPT. Наши цифры для Claude — только старое поколение.

## Опыт 2. Случайность: «Придумай название для кофейни» ×3

Один и тот же промпт отправлен три раза в чистые контексты (каждый «чат» — отдельный субагент Claude Sonnet 5.5, температура по умолчанию, друг друга они не видели). Скрипт: `exp02_randomness_coffee_names.py`. Отчёт: [results/exp02_randomness_coffee_names.md](results/exp02_randomness_coffee_names.md), дословные ответы: [results/exp02_raw_answers.md](results/exp02_raw_answers.md).

- Каждый чат выдал по 12 названий: всего **36**, уникальных **29**.

**Названия по чатам:**

| Чат | Названия | Выбор чата |
|---|---|---|
| chat1 | Зерно, Крема, Тёплый угол, Утро в чашке, Ристретто, Обжарка №1, Кофе и точка, Ещё по одной, Бариста Бар, Чёрная пятница, Арабика Club, Пенка | Зерно, Тёплый угол |
| chat2 | Зерно & Ко, Кружка, Тёплый берег, Обжарка №7, Крема, Ристретто, Кофе на посошок, Эспрессо Патронум, Утро добрым не бывает, Bean There, Daily Grind, Slow Pour | Зерно & Ко, Крема |
| chat3 | Зерно & Плед, Третья чашка, Тёплый угол, Обжарка, Ристретто, Крема, Кофе-пауза, Ещё по одной, Бодрый четверг, Brew Nook, Mokka, Bean There | Третья чашка |

**Дословные повторы:**

| Название | Чатов |
|---|---|
| Крема | 3/3 |
| Ристретто | 3/3 |
| Тёплый угол | 2/3 |
| Ещё по одной | 2/3 |
| Bean There | 2/3 |

**Повторяющиеся идеи (общий корень), все три чата:** «Зерно…» (Зерно, Зерно & Ко, Зерно & Плед), «Обжарка…» (№1, №7, просто «Обжарка»), «Тёплый…» (угол, берег).

**Сходство пар чатов (индекс Жаккара по точным совпадениям):** chat1-chat2 = 0.09, chat1-chat3 = 0.2, chat2-chat3 = 0.14.

**Вывод:** ответы не идентичны, но все три чата вертятся вокруг одного набора клише (зерно, крема, ристретто, обжарка, тёплый уют). Случайность проявляется в деталях (редкие названия вроде «Эспрессо Патронум», «Brew Nook», разные «лучшие»), центр ответов почти один и тот же. Выборка из 3 запусков очень мала; для надёжных выводов нужно 20–30 запусков через API с заданной температурой.

## Опыт 3. Токенайзеры на 7 языках

## Что измеряли другие

Сводка поиска по сети (ноябрь 2026), подробно с пометками «прочитан» или «по выдаче»: [results/related_work_tokenizers.md](results/related_work_tokenizers.md). Источники — блоги и препринты, не рецензируемые работы.

- **Claude против GPT на 7 языках** ([dev.to, SAVI](https://dev.to/savi444/tokens-per-word-gpt-5-vs-claude-vs-gpt-4-measured-across-7-languages-4419), прочитан): на английском GPT-5 — 110 токенов, Sonnet 4.6 — 116, Opus 4.8 — 177; на немецком 159, 245 и 324; на китайском и японском Claude почти не отличается от GPT-5. Русского в тесте нет, один короткий текст на язык.
- **Русский, исследование Donseo в пересказе** ([www1.ru](https://www1.ru/en/news/2026/10/05/440386-ssa-berut-s-rossiian-bolse-za-russkii-iazyk-claude-tratit-pocti-v-4-raza-bolse-tokenov.html), прочитан пересказ без оригинала): русский на Claude Opus 5 занимает почти втрое больше токенов, чем английский, и в 3.9 раза больше, чем на GPT-5.5; метод в статье не описан.
- **Код** ([PlayCode](https://playcode.io/blog/real-price-of-frontier-models), по выдаче): у последнего токенайзера Claude в 1.73 раза больше токенов на TypeScript, чем у GPT-5.x.
- **Внутри Claude** ([Simon Willison](https://feeds.simonwillison.net/tags/tokenization/), по выдаче): Opus 4.7 против Opus 4.6 — ×1.46.
- **Казахский** ([SozKZ, arXiv 2603.20854](https://arxiv.org/html/2603.20854v1), по выдаче): универсальные токенайзеры дают 4.9–6.6 токена на слово, специализированный — 1.3–1.4 (10 предложений).

Наши цифры для GPT-4/4o, Qwen3, Gemma 3 и Llama 4 по порядку величины согласуются с внешними. Колонка Claude 1/2 у нас, вероятно, занижает стоимость русского и казахского в современных Claude.

## Ограничения

- Claude 3+ и 5 не измерены: токенайзер закрыт, нужен `ANTHROPIC_API_KEY` и API `count_tokens`. Колонка «Claude 1/2 (legacy)» — старое поколение со словарём 65k, лишь грубый ориентир.
- Тексты и переводы (казахский, турецкий, немецкий, китайский, русский транслит) написаны вручную и носителями не проверялись. Корпус маленький: 6 параллельных текстов, выводы о порядке величины.
- Опыт 2: выборка 3 запуска, температура не задавалась; субагенты работают внутри Claude Code с его системным промптом, это не чистый веб-чат.
- Токенайзеры OpenAI и open-weight посчитаны локально; сравниваются числа токенов, а не качество ответов или реальная цена.
