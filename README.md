# llme_experements

Опыты с LLM. Каждый опыт — скрипт `expNN_*.py` + отчёт в `results/`.

## Окружение

```bash
python3 -m venv .venv
.venv/bin/pip install tiktoken
```

## Опыты

| # | Опыт | Скрипт | Отчёт |
|---|------|--------|-------|
| 1 | Токенизация одной фразы: RU, RU-латиницей, EN, KK | `exp01_tokenization_ru_vs_en.py` | [results/exp01_tokenization_ru_vs_en.md](results/exp01_tokenization_ru_vs_en.md) |
| 2 | Случайность: «Придумай название для кофейни» ×3 в новых чатах | `exp02_randomness_coffee_names.py` | [results/exp02_randomness_coffee_names.md](results/exp02_randomness_coffee_names.md) |

### Опыт 1 — главный результат

Языки: английский (база), русский, русский латиницей (транслит), казахский.
Число токенов относительно английского (3 фразы, диапазон):

| Токенайзер | Русский | Русский латиницей | Казахский |
|---|---|---|---|
| `cl100k_base` (GPT-4) | 1.75–2.3x | 1.25–2.18x | 2.5–4.05x |
| `o200k_base` (GPT-4o) | 1.22–1.36x | 1.25–2.05x | 1.33–1.82x |

- На новом токенайзере кириллица подешевела сильнее всего: русский почти догнал английский.
- Транслит не выручает: на `o200k_base` он вдвое дороже английского и заметно дороже русской кириллицы.
- Казахский самый дорогой: на `cl100k_base` до 4x (специфические буквы ә, ө, ү, қ, ң, ғ, і, һ режутся на байты).

### Опыт 2 — главный результат

Один промпт, три независимых запуска с чистым контекстом (Sonnet 5.5). Каждый чат выдал по 12 названий, всего 36, уникальных 29.

- Дословно во всех трёх чатах повторились «Крема» и «Ристретто».
- По корню идеи во всех трёх: «Зерно…», «Обжарка…», «Тёплый…».
- Но «лучший» выбор у всех разный: «Зерно» / «Зерно & Ко» / «Третья чашка».

Вывод по выборке из 3: ответы не идентичны, но модель крутится вокруг одного и того же набора клише. Случайность есть в деталях, в центре тяжести её почти нет.
