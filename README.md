# llme_experements

Опыты с LLM. Каждый опыт — скрипт `expNN_*.py` + отчёт в `results/`.

## Окружение

```bash
python3 -m venv .venv
.venv/bin/pip install tiktoken
```

```bash
.venv/bin/pip install tokenizers huggingface_hub anthropic
```

### Опыт 1 — главный результат

Три фразы (короткая, средняя, длинная) на 5 языках/письменностях, для каждого токенайзера из опыта 3.
Среднее число токенов относительно английского:

| Токенайзер | Русский | Рус. латиницей | Казахский | Китайский |
|---|---:|---:|---:|---:|
| GPT-4 (cl100k) | 2.08x | 1.74x | 3.25x | 1.64x |
| GPT-4o (o200k) | 1.28x | 1.77x | 1.55x | 1.01x |
| Qwen3 | 1.54x | 1.74x | 2.56x | 0.92x |
| Gemma 3 | 1.18x | 1.71x | 1.98x | 0.93x |
| Llama 4 | 1.21x | 1.73x | 1.90x | 1.01x |
| Claude 1/2 (legacy) | 2.38x | 1.79x | 3.33x | 1.50x |

- Старые токенайзеры (GPT-4, Claude 1/2) берут за русский и казахский в 2–4 раза больше токенов, новые с большим словарём (GPT-4o, Gemma 3, Llama 4) — в 1.1–2 раза.
- Китайский на новых токенайзерах не дороже английского и часто дешевле (0.7–1.0x); на GPT-4 и Claude 1/2 дороже в 1.4–1.75 раза.
- Транслит (русский латиницей) везде дороже кириллицы на новых токенайзерах и примерно равен ей на старых.

### Опыт 2 — главный результат

Один промпт, три независимых запуска с чистым контекстом (Sonnet 5.5). Каждый чат выдал по 12 названий, всего 36, уникальных 29.

- Дословно во всех трёх чатах повторились «Крема» и «Ристретто».
- По корню идеи во всех трёх: «Зерно…», «Обжарка…», «Тёплый…».
- Но «лучший» выбор у всех разный: «Зерно» / «Зерно & Ко» / «Третья чашка».

Вывод по выборке из 3: ответы не идентичны, но модель крутится вокруг одного и того же набора клише. Случайность есть в деталях, в центре тяжести её почти нет.

### Опыт 3 — главный результат

6 параллельных текстов × 7 языков/письменностей + 5 нейтральных (числа, код, JSON, URL, эмодзи). Среднее число токенов относительно английского:

| Токенайзер | Русский | Рус. латиницей | Казахский | Турецкий | Немецкий | Китайский |
|---|---:|---:|---:|---:|---:|---:|
| GPT-4 (cl100k) | 1.97x | 1.68x | 3.06x | 1.69x | 1.39x | 1.61x |
| GPT-4o (o200k) | 1.11x | 1.59x | 1.41x | 1.28x | 1.15x | 1.03x |
| Qwen3 | 1.45x | 1.68x | 2.45x | 1.39x | 1.37x | 0.83x |
| Gemma 3 | 1.08x | 1.58x | 1.86x | 1.20x | 1.15x | 0.90x |
| Llama 4 | 1.05x | 1.59x | 1.71x | 1.24x | 1.12x | 0.89x |
| Claude 1/2 (legacy, 65k) | 2.22x | 1.76x | 3.17x | 2.05x | 1.57x | 1.49x |

- Новые токенайзеры с большим словарём (200–260k) почти уравняли русский с английским; Qwen3 (словарь 151k) отстаёт.
- Казахский везде дороже всех: от 1.4x до 3x. Транслит стабильно ~1.6x независимо от модели.
- Китайский на Qwen3, Gemma 3 и Llama 4 дешевле английского (0.83–0.90x).
- Qwen3 и Gemma 3 режут числа по цифрам (54 и 53 токена против 34 у GPT-4o и Llama 4 на строке с номерами).
- Claude: токенайзеры Claude 3+ и 5 закрыты. Без ключа удалось взять только публичный токенайзер Claude 1/2 (словарь 65k, `Xenova/claude-tokenizer`): он на уровне GPT-4 или хуже (русский 2.22x, казахский 3.17x), но это старое поколение и для актуальных моделей лишь грубый ориентир.
  Точные числа для Claude 5.x даёт только API `count_tokens`: `ANTHROPIC_API_KEY=... .venv/bin/python exp03_tokenizers_multi.py`.
